# 파이썬 주식 투자 실습 노트

이 저장소는 파이썬을 활용한 주식 투자 시스템 구축 및 데이터 분석 실습 내용을 정리한 공간입니다. 제공된 교재의 각 장별 마크다운 파일에서 핵심 파이썬 코드만을 추출하여 Jupyter Notebook(`.ipynb`) 형식으로 구성하였습니다.

## 📂 폴더 구조

- **1장/**: 기초 다지기 (파이썬 기본 및 데이터 사이언스 기초 실습)
- **2장/**: 국내 주식 분석하기 (데이터 수집 및 기술적 지표 분석 실습)
- **3장/**: LLM과 MCP 활용하기 (LLM 프롬프트 및 MCP 실습)
- **4장/**: (실습 준비 중)
- **5장/**: (실습 준비 중)

## 🚀 실습 방법

각 폴더 내의 `*_실습.ipynb` 파일을 실행하여 코드 블록별로 실습을 진행할 수 있습니다. 각 코드 블록 상단에는 해당 코드가 포함된 원문 파일명을 명시하여 참조가 용이하도록 구성했습니다.
