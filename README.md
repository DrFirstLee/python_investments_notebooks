# 파이썬 주식 투자 실습 노트

이 저장소는 파이썬을 활용한 주식 투자 시스템 구축 및 데이터 분석 실습 내용을 정리한 공간입니다. 제공된 교재의 각 장별 마크다운 파일에서 핵심 파이썬 코드만을 추출하여 Jupyter Notebook(`.ipynb`) 형식으로 구성하였습니다.

## 📂 폴더 구조

- **1장/**: 기초 다지기
- **2장/**: 국내 주식 분석하기
- **3장/**: 미국 주식 멀티팩터 실전 투자 전략
  - **3장_mcp상세/korea-stock-mcp/**: 실시간 국내 주식 데이터 분석을 위한 MCP 소스 코드 및 실습 환경
- **4장/**: 제미나이를 활용해 시장 분석하고 종목 추천 받기
- **5장/**: MCP를 활용하여 실시간 주식 데이터 기반으로 분석하기

## 🚀 실습 방법

각 폴더 내의 `1장.ipynb`, `2장.ipynb` 등 각 장별 `.ipynb` 파일을 실행하여 코드 블록별로 실습을 진행할 수 있습니다. 각 코드 블록 상단에는 해당 코드가 포함된 원문 파일명을 명시하여 참조가 용이하도록 구성했습니다.

특히 **3장/** 하위의 `korea-stock-mcp/` 폴더에는 LLM과 연동하여 실시간 주식 데이터를 조회하고 분석할 수 있는 MCP(Model Context Protocol) 시스템 개발용 핵심 소스 코드가 포함되어 있습니다.
